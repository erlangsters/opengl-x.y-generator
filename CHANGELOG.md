# Changelog

Notable user-facing changes to the Erlangsters [opengl-x.y-generator](https://github.com/erlangsters/opengl-x.y-generator) repository are documented here.

## 0.1.0

### Added

- Initial release of the OpenGL binding generator.
- Generation of `gl.erl`, `gl.hrl`, and `gl.c` for OpenGL 3.3, 4.1, 4.6 and OpenGL ES 2.0, 3.0, 3.1, 3.2.
